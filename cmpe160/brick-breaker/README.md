# Brick Breaker

The classic brick breaker game. Move the paddle, bounce the ball and break all the bricks.

**Course:** CMPE 160 Object-Oriented Programming, Spring 2025 · Java

## Highlights

- Ball movement and bounces off walls, the paddle and bricks
- Aiming for the first shot, pause, score, and victory and game over screens
- `MainModified.java` is a second version where the paddle can also move up and down

## Run

```sh
javac -cp lib/stdlib.jar -d out src/*.java
java -cp out:lib/stdlib.jar Main
```

On Windows, use `;` instead of `:` in the class path.
