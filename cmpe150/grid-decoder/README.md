# Grid Decoder

Finds words hidden in a grid of letters and symbols, and lists every path that spells each word.

**Course:** CMPE 150 Introduction to Computing, Fall 2024 · Python

## Highlights

- Searches the grid recursively in all 8 directions
- Sorts the paths for each word from shortest to longest, where diagonal steps count as longer

## Run

```sh
python3 main.py
```

Prints the result for the example grid in `main.py`.
